<h3>Our Tools</h3>

<div style = "margin: 10px 20px 20px 20px;">
<span style = "font-weight: bold;">SSETracer and StrandTwister </span>
<br>
Description:
<br><div style = "margin: 0px 20px 0px 20px;">A secondary structure detection and modeling tool aimed to detect alpha-helices, beta-sheets from protein electron cryo-microscopy (cryoEM) maps at medium resolutions.</div> 
Citation:
<br><div style = "margin: 0px 20px 0px 20px;">Si, D., He, J. "Beta-sheet Detection and Representation from Medium Resolution Cryo-EM Density Maps" <span style = "font-style:italic;">Proceeding of ACM Conference on Bioinformatics Computational Biology and Biomedicine Workshops, Washington, D.C., September 22-25</span>, 2013.</div>
<br><div style = "margin: 0px 20px 0px 20px;">Si, D., He, J. "Tracing Beta-strand using StrandTwister from the Cryo-EM Density Maps at Medium Resolutions" 22(11):1665-76,<span style = "font-style:italic;"> Structure</span>, 2014.</div>
Website:
<br><div style = "margin: 0px 20px 0px 20px;"><a href = "http://www.cs.odu.edu/~bioinfo/NSF-Products.htm" target = "show">SSETracer and StrandTwister homepage</a></div>
</div>
<br>


<div style = "margin: 10px 20px 20px 20px;">
<span style = "font-weight: bold;">DP-TOSS (a Dynamic Programming algorithm to derive Topologies Of the Secondary Structure elements from CryoEM protein density)</span>
<br>
Description: 
<br><div style = "margin: 0px 20px 0px 20px;">A program to generate the possible topologies of the secondary structue elements.</div>

Citation:
<br><div style = "margin: 0px 20px 0px 20px;">Al Nasr, K., Ranjan, D., Zubair, M., He, J. "Ranking valid topologies of the secondary structure elements using a constraint graph", <span style = "font-style:italic;">Journal of Bioinformatics and Computational Biology</span>, Vol 9(3), 415-30, 2011.</div>
<br><div style = "margin: 0px 20px 0px 20px;">Al Nasr, K., Ranjan, D., Zubair, M., Chen, L., He, J. "Solving the secondary structure matching problem in de novo modeling using a constrained K-shortest path graph algorithm", <span style = "font-style:italic;">IEEE Transactions on Computational Biology and Bioinformatics</span>, 11(2), 419-29, 2014.</div>

<div style = "margin: 10px 20px 20px 20px;">
<span style = "font-weight: bold;">DOKB (a Distance & Orientation Dependent protein energy function of Key Blocks)</span>
<br>
Description: 
<br><div style = "margin: 0px 20px 0px 20px;">A program to calculate the potential energy of protein structure.</div>
Citation:
<br><div style = "margin: 0px 20px 0px 20px;">Chen, L., He, J. "A distance and orientation-dependent energy function of amino acid key blocks", Biopolymers 101(6), 681-92, 2014.</div>

</div>

<div style = "margin: 10px 20px 20px 20px;">
<span style = "font-weight: bold;">Helixtracer </span>
<br>
Description: 
<br><div style = "margin: 0px 20px 0px 20px;">A program to detect the location of helices from a density map of proteins typically generated by electron cryo-microscopy.</div>
